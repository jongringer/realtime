# 4조 3교대 스마트 근무표 웹 애플리케이션

4조 3교대(일근-야근-조근-비번) 근무자의 교대 패턴을 자동으로 계산하고, 비번 미표기 규칙, PDF/사진 근무표 인식 및 대근/휴가 변경, 개인 일정 관리를 지원하는 맞춤형 웹 앱입니다.

---

## 🌟 주요 기능 및 특징

1. **4조 3교대 패턴 자동 계산**:
   - 순환 주기: **일근 → 야근 → 조근 → 비번** (4일 주기)
   - 전달 마지막 날(예: 8월 31일이 조근이면 9월 1일은 비번)을 기준으로 다음 달 및 향후 모든 달의 기본 근무표를 자동 계산.
   - **비번 미표시**: 비번(휴무) 날짜는 캡처 이미지와 동일하게 캘린더에 뱃지를 표기하지 않고 공백으로 처리.

2. **근무표 PDF / 사진 업로드 인식 (OCR)**:
   - `[📋 근무표 업데이트 (PDF / 사진 등록)]` 버튼 지원.
   - 근무표 PDF 문서나 사진/이미지(PNG, JPG 등)를 업로드하면 Tesseract.js / PDF.js를 통해 텍스트를 추출하고, 대근/휴가 변경 사항을 자동 인식.
   - 인식된 결과를 테이블에서 확인/수정 후 즉시 근무표에 반영.

3. **캡처 화면과 1:1 일치하는 정밀 디자인**:
   - 상단 프로필: `최종철 님`, `생방기술1 · 직무 NDC`
   - 오늘 근무 안내 카드: `9월 17일 (목)`, `⚡ 일근대근`, `09:00 ~ 18:00 (대근)`
   - 다크 캘린더: 선택/오늘 날짜 네온 그린 테두리 강조, 날짜별 ⏰ 알람 아이콘, 색상별 근무 뱃지(일근: 파랑, 야근: 주황/머스타드, 조근: 보라, 일근대근: 빨강, 일근휴가: 녹색)
   - 달력 내 개인 일정 뱃지: `📌 서울성모병원`
   - 하단 교대근무 기준 가이드 카드

4. **개인 일정 등록 및 관리**:
   - 날짜 및 시간(예: 오후 6:37, 오전 07:00 등)을 지정하여 일정 등록.
   - 등록 시 달력 해당 날짜 셀에 즉시 `📌 [일정명]` 표출.
   - 하단 등록된 일정 목록에서 원클릭 삭제(`✕`) 가능.

5. **날짜별 근무 수동 변경 (원클릭/더블클릭)**:
   - 달력의 특정 날짜를 더블클릭하면 팝업이 떠서 일근대근, 야근대근, 휴가, 비번 등 원하는 형태로 즉시 수정 가능.

6. **데이터 영구성 (LocalStorage)**:
   - 모든 수정 내역, 일정, 프로필, 기준일 설정이 브라우저에 자동 보존됩니다.

## 🚀 실행 방법

### 방법 1: 파일 더블클릭으로 바로 실행 (가장 간단)
- `index.html` 파일을 더블클릭하여 크롬, 엣지, 웨일 등 브라우저에서 바로 사용하실 수 있습니다.
- 또는 `start.bat`을 실행하고 1번을 선택하세요.

### 방법 2: 로컬 Node.js 웹 서버 구동
```bash
node server.js
```
- 브라우저에서 `http://localhost:3000` 접속
